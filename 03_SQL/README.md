# MySQL Sales Analysis

This folder contains SQL queries used to analyze the Amazon India Sales 2025 dataset.

## Analysis Objectives
- Calculate total sales and order counts
- Compare product category performance
- Analyze average order value
- Examine returned orders
- Analyze state-wise sales performance
- Explore customer purchasing patterns

## Tools
MySQL and MySQL Workbench

The analysis uses the same 15,000-record dataset explored in Python and visualized in Power BI.
