# Power BI Dashboard

This folder contains the interactive Power BI dashboard developed for the Amazon India Sales 2025 Analysis project.

## Dashboard Pages

### Page 1 — Sales Overview
Provides an overview of sales performance, KPIs, trends, and key business metrics.

### Page 2 — Detailed Analysis
Explores product, category, state, and other performance insights.

## Features
- Interactive slicers and filters
- DAX measures for business KPIs
- Sales and performance comparisons
- Dashboard navigation
- Two-page analytical report
