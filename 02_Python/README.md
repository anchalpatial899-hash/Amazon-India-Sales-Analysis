# Python Exploratory Data Analysis

This folder contains the Jupyter Notebook used to analyze the Amazon India Sales 2025 dataset.

## Analysis Covered
- Data inspection and preparation
- Monthly sales trends
- Product and category performance
- State-wise sales analysis
- Customer purchasing patterns
- Order and delivery status
- Returns and payment methods
- Customer ratings and quantity distribution

## Tools
Python, Pandas, NumPy, Matplotlib and Jupyter Notebook.
